# Reeshika Travels website

A responsive static website built from the supplied Stitch screens and VoyageOS design system.

## Pages

- `index.html` — home page and trip enquiry form
- `fleet.html` — vehicle cards and category filters
- `outstation-trips.html` — trip types, quote request and fare notes
- `contact.html` — contact options and enquiry form
- `assets/reeshika-logo-mark.png` — logo mark extracted from the supplied Sunrise Road PDF

## Preview

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

The forms open WhatsApp with the entered trip details addressed to +91 78159 89020. They do not submit to a website backend. Vehicle photography and web fonts are loaded from the external URLs present in the supplied design files, so those visual assets need an internet connection.
